HOW IT WORKS

From raw events to rich stories.

01

Dual Ingest Paths

GateStory receives Ring camera events through two paths simultaneously: an outbound Event History Poller hitting api.amazonvision.com, and an inbound HMAC-verified webhook receiver. Both paths feed the same deduplication layer.

Ring API HMAC-SHA256 Deduplication
[ring] GET /v1/history/devices/{'{id}'}/events
200 OK · 1 event · api.amazonvision.com
[webhook] POST /api/ring/webhook
✓ HMAC verified · timingSafeEqual
[dedup] Event merged into session
02

Temporal Correlation

The Correlation Engine windows events by camera zone sequence — gate(0) → walkway(1) → door(2) — within a 90-second merge gap. Each correlated sequence becomes a structured VisitSession with dwell times per zone.
